## Goal

A public GitHub repo (`VietThan/agent-cli-plugin`) that:
- Installs as a Claude Code plugin via `--plugin-dir`

---

## Key Insight: Formats Are Already Unified

All three targets use the same skill folder structure. No sync scripts or generated files needed.

| Target | Skill path | Discovery |
|---|---|---|
| Claude Code (plugin) | `skills/<name>/SKILL.md` | Via `plugin.json` |
| agentskills.io | `skills/<name>/SKILL.md` | `.agents/skills/<name>/SKILL.md` |
| OpenAI Codex | `<name>/SKILL.md` | `.agents/skills/<name>/SKILL.md` |

Claude Code is the originator of the agentskills.io standard — the formats are intentionally identical. The only delta: Codex/agentskills.io discover skills from `.agents/skills/`, while Claude's plugin reads from `skills/` at plugin root. A single symlink bridges the gap.

## SKILL.md Format

Each `SKILL.md` uses YAML frontmatter (Claude-specific fields) followed by agentskills.io-compatible markdown instructions. Codex and agentskills.io ignore unknown frontmatter fields gracefully.

```markdown
---
name: commit
description: Create a conventional commit for staged changes. Use when the user wants to commit, has staged changes, or asks to save work.
disable-model-invocation: true
allowed-tools: Bash(git add *) Bash(git commit *) Bash(git status *) Bash(git diff *)
argument-hint: "[optional scope or message]"
---

Create a conventional commit for staged changes.

1. Run `git diff --cached` to review staged changes
2. Infer the conventional commit type: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `ci`
3. Write a subject line under 72 characters
4. Include a co-author trailer: `Co-Authored-By: Claude <noreply@anthropic.com>`
5. Commit using a heredoc to preserve formatting

$ARGUMENTS
```

## Public vs Private

Start public. Rationale:
- Skills contain no secrets — just prompts and instructions
- Easier to share: `claude --plugin-dir <git-clone-path>`
- GitHub makes flipping private a single toggle with no structural changes
- If a skill ever needs private context (tokens, internal URLs), that context lives in local env or a separate private overlay — not in the plugin
