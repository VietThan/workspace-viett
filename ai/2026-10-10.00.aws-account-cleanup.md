# AWS Account Cleanup — our-adventures Teardown

**Date:** 2026-10-10

## Context

`our-adventures` was not being used by Viet or Linh. Tore down all infrastructure to stop paying ~$20–25/month. All application data (adventure entries) was considered non-critical and discarded.

## What Was Deleted

| Resource | Stack | Savings |
|---|---|---|
| EC2 t4g.nano | our-adventures / ComputeStack | ~$2.50/month |
| Elastic IP | our-adventures / ComputeStack | ~$3.60/month |
| RDS t4g.micro PostgreSQL 18 | shared-aws-infra / DatabaseStack | ~$13–15/month |
| RDS storage + 7-day backups | shared-aws-infra / DatabaseStack | ~$3/month |
| VPC, subnets, security groups | shared-aws-infra / NetworkStack | free |
| GuardDuty, CloudTrail trail, IAM OIDC/roles | shared-aws-infra / SecurityStack | ~$1/month |
| AWS Budgets + Cost Anomaly Detection | shared-aws-infra / BillingStack | free |
| 7 SSM SecureString parameters | manual | free |

All 5 CDK stacks destroyed: `ComputeStack`, `DatabaseStack`, `NetworkStack`, `BillingStack`, `SecurityStack`.

## What Remains (as of teardown)

| Resource | Monthly Cost | Notes |
|---|---|---|
| RDS final snapshot (20 GB) | ~$1.90/month | Auto-created on instance deletion — **delete if no restore needed** |
| CloudTrail S3 bucket (~94 MB) | ~$0.002/month | Retained by design (`RemovalPolicy.RETAIN`); safe to delete manually |
| CDKToolkit stack + bootstrap S3 bucket | ~$0/month | Needed to redeploy CDK in future |
| `/cdk-bootstrap/hnb659fds/version` SSM param | free | Part of CDK bootstrap |
| 4 KMS keys (AWS-managed) | free | Not customer-managed; cannot be deleted |
